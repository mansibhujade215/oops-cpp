# Unit 2 – Inheritance

### Program 1: Single Inheritance
**Description:**  
This program demonstrates single inheritance, where one derived class inherits the properties and functions of one base class.

### Program 2: Multiple Inheritance
**Description:**  
This program demonstrates multiple inheritance, where one derived class inherits from more than one base class.

### Program 3: Multilevel Inheritance
**Description:**  
This program demonstrates multilevel inheritance in which a class is derived from another derived class.

### Program 4: Hierarchical Inheritance
**Description:**  
This program demonstrates hierarchical inheritance, where multiple derived classes inherit from a single base class.

# Unit 3 – Polymorphism and Virtual Functions

### Program 1: Function Overloading
**Description:**  
This program demonstrates function overloading by defining multiple functions with the same name but different parameters.

### Program 2: Operator Overloading
**Description:**  
This program demonstrates operator overloading, which allows operators to work with user-defined objects.

### Program 3: Function Overriding
**Description:**  
This program demonstrates function overriding, where a derived class provides its own implementation of a base class function.

### Program 4: Virtual Function
**Description:**  
This program demonstrates the use of virtual functions to achieve runtime polymorphism in C++.
